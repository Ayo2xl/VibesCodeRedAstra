# VibesCodeRedAstra

This is a simple Python script that uses the ElevenLabs API to convert text to speech. It takes in a text string, a voice ID, and an output file name as arguments, and then uses the ElevenLabs API to convert the text to speech and save it to the specified output file.

To use this script, you will need to have the ElevenLabs API key, which you can obtain by signing up for an account on the ElevenLabs website. Once you have the API key, you can set it as an environment variable.
